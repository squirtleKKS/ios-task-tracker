TaskTracker — Лабораторная работа №3 (Авторизация)

## Как запустить
	1.	Открыть проект в Xcode
	2.	Выбрать симулятор (например, iPhone 15)
	3.	Нажать Run (⌘ + R)

Приложение стартует с экрана авторизации.

# Данные для входа

Для успешной авторизации используются захардкоженные данные:

Email: admin
Password: admin

## Важно
	•	При вводе любых других данных будет показана ошибка:

Неверный email или пароль

Поведение приложения

При успешном входе:
	•	Открывается экран Features (Фичи)
	•	Экран содержит список доступных фич (заглушки):
	•	Задачи
	•	Статистика
	•	Напоминания
	•	При нажатии на любую фичу открывается экран-заглушка

# При ошибке входа:
	•	Отображается сообщение об ошибке
	•	Переход на следующий экран не происходит

# Logout:
	•	На экране Features есть кнопка Logout
	•	При нажатии:
	•	происходит выход из системы
	•	пользователь возвращается на экран авторизации


# Допы:
	• return на клавиатуре переключает фокус (логин → пароль → submit)
	• Визуальная обработка ошибок (inline под полем, подсветка, сообщение рядом с кнопкой)
