# TaskTracker — Лабораторная работа №4

## Какое API используется

Используется публичное API:

- API: `JSONPlaceholder`
- Endpoint: `/todos`

Полный URL: https://jsonplaceholder.typicode.com/todos

Пример ответа

Пример элемента ответа:
```
{
  "userId": 1,
  "id": 1,
  "title": "delectus aut autem",
  "completed": false
}
```

API возвращает массив таких объектов.

Описание:

	•	userId — идентификатор владельца

	•	id — идентификатор задачи

	•	title — заголовок задачи

	•	completed — выполнена ли задача


Во view слой передаётся:
```
struct TaskItemVM: Equatable {
    let id: TaskID
    let title: String
    let status: TaskStatus
    let priority: TaskPriority
    let deadlineText: String?
}
```
Используемые поля:

	•	id — идентификатор задачи

	•	title — заголовок

	•	status — статус задачи

	•	priority — приоритет

	•	deadlineText — строка с дедлайном, подготовленная для отображения

Как проверить

	1.	Запустить приложение

	2.	Выполнить вход/регистрацию (admin admin/любые креды)

	2.	Нажать на пункт Задачи

	3.	Откроется экран Tasks

	4.	При открытии TasksViewModel.onAppear() запускает загрузку данных из сети



Выполненные допы:

### **D1. Нормальная модель ошибок**

Сделать свой тип ошибки (например NetworkError) и маппить её в текст/состояние для UI (не “URLError.description” напрямую).

### **D2. Отмена запроса (cancellation)**

Если повторно вызывается загрузка (например “Retry”), предыдущий запрос должен отменяться (или игнорироваться результат старого).
