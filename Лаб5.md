# **Лабораторная №5 — Экран списка (UIKit) + переиспользуемые компоненты**

## Подход к списку

Использован `UITableView`.

Почему:
- встроенный механизм переиспользования ячеек (`reuseIdentifier`)
- простой API
- достаточная производительность для 100+ элементов

Работа со списком вынесена в `TasksListManager`, который:
- хранит элементы (`TaskTableViewCell`)
- реализует `UITableViewDataSource` и `UITableViewDelegate`
- сообщает о выборе элемента через делегат

---

## Как открыть экран списка

1. Запустить приложение  
2. Ввести:
   - email: `admin`
   - password: `admin`
3. После входа открыть раздел **"Задачи"**

---

## Состояния экрана

Реализованы состояния:

- **loading** — при открытии экрана  
- **content** — отображение списка задач  
- **empty** — если нет данных или поиск ничего не нашёл  
- **error** — при ошибке загрузки (есть кнопка "Повторить")

---

## Дополнительные задания

### Pull-to-refresh
- реализован через `UIRefreshControl`
- потянуть список вниз → обновление данных

### Поиск
- реализован через `UISearchController`
- поиск выполняется локально по элементам списка
- без повторного запроса в сеть

---

## Как проверить работу

### Loading
- открыть экран задач после авторизации

### Content
- появляется автоматически после загрузки списка

### Empty
- ввести в поиск строку, по которой нет совпадений

### Error
- нажать кнопку `Error` в navigation bar  
- после появления ошибки нажать **"Повторить"** для повторной загрузки

### Pull-to-refresh
- потянуть список вниз - данные перезагружаются

### Поиск
- ввести текст в search bar - список фильтруется

---

## Что происходит по tap

При нажатии на элемент списка:
- вызывается обработка выбора
- открывается экран деталей задачи (заглушка)
