# Лабораторная №6 — Дизайн-система

## Описание

В проекте реализована собственная дизайн-система и применена на экранах приложения.  
Цель — централизовать управление стилями (цвета, шрифты, отступы, компоненты) и обеспечить единый визуальный стиль интерфейса.

---

## Дизайн-система

Дизайн-система вынесена в отдельную папку:

DesignSystem/

### Токены

Реализованы следующие токены:

- **Colors**
  - background
  - surface / surfaceSecondary
  - primary / primaryPressed / primaryDisabled
  - textPrimary / textSecondary
  - border / separator
  - error / success

- **Typography**
  - largeTitle
  - title
  - heading
  - body / bodyMedium
  - caption / captionMedium
  - button

- **Spacing**
  - xs / s / m / l / xl / xxl

- **CornerRadius**
  - s / m / l / pill

---

## Компоненты

Реализованы переиспользуемые UI-компоненты:

- **DSButton**
  - primary / secondary
  - состояния: normal / pressed / disabled

- **DSTextField**
  - заголовок
  - placeholder
  - отображение ошибки

- **DSLoadingView**
  - индикатор загрузки + текст

- **DSMessageView**
  - используется для состояний empty / error
  - поддерживает кнопку действия (retry)

---

## Применение

Дизайн-система применена на экранах:

- **Auth (экран авторизации)**
- **Features (список фич)**
- **Tasks (список задач)**

Все “ручные” стили заменены на токены дизайн-системы.

---

## Состояния экранов

Используются единые компоненты:

- **Loading** — DSLoadingView  
- **Error** — DSMessageView  
- **Empty** — DSMessageView  

---

## Архитектура

- Дизайн-система вынесена отдельно (DesignSystem)
- UI-компоненты не содержат бизнес-логики
- ViewController отвечает только за управление состоянием

---

## Как проверить

### Loading
- открыть экран Tasks или Features

### Error
- нажать кнопку **Error** в navigation bar на экране Tasks

### Empty
- вернуть пустой список из сервиса

### Pull-to-refresh
- потянуть список задач вниз

### Поиск
- использовать search bar на экране задач
